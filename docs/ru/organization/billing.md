# Биллинг

{% note info "" %}

Раздел «Биллинг» доступен только пользователям с уровнем доступа **Администратор**.

{% endnote %}

Раздел «Биллинг» хранит информацию о тарифном плане организации, балансе и платежных документах. Эти данные используются для оплаты сервиса и получения закрывающих документов.

В разделе четыре вкладки:

- **Обзор** – текущий тариф, баланс и использование за период;
- **Тарифы** – сравнение тарифов и переход на другой тариф;
- **История** – операции по балансу и счета на оплату;
- **Акты** – закрывающие документы за оплаченные периоды.

## Обзор

![Вкладка «Обзор»](../_files/billing/overview.png)

### Текущий тариф

В карточке тарифа отображаются:

- **Цена / мес** – стоимость тарифа в месяц;
- **Паспортов / мес** – лимит выпуска паспортов (∞ – без ограничений);
- **Хранилище** – лимит объёма файлов (∞ – без ограничений);
- **Каталог** – demo или полный;
- **Размещение** – где размещены данные (серверы в РФ).

Кнопка **Сменить тариф** открывает вкладку «Тарифы».

### Баланс

С баланса списывается оплата тарифа при продлении периода. В карточке баланса отображаются:

- текущий баланс;
- **Расчётный период** – даты начала и окончания периода и сколько дней осталось;
- **Следующее списание** – сумма и дата оплаты тарифа.

Если средств недостаточно, выводится предупреждение: *«Не хватает 4 900,00 ₽. Пополните баланс до 24.09.2026 – иначе списание за тариф не пройдёт»*.

### Использование

Блок «Использование» показывает потребление за текущий расчётный период:

- **Паспорта** – сколько паспортов создано;
- **Хранилище** – суммарный объём загруженных файлов.

### Пополнение баланса

1. Нажмите **Пополнить баланс**.
2. Введите сумму пополнения в рублях. Минимальная сумма – 100 ₽, оплата – банковским переводом по счёту.
3. При необходимости нажмите подсказку **Следующее списание – … ₽**, чтобы подставить сумму предстоящего списания.
4. Нажмите **Выставить счёт** – система сформирует счёт на оплату по банковским реквизитам организации. Средства зачисляются после поступления на расчётный счёт. Кнопка **Отмена** закрывает окно без создания счёта.

![Окно «Пополнение баланса»](../_files/billing/topup.png)

## Тарифы

Во вкладке «Тарифы» выберите план, подходящий вашей организации.

![Вкладка «Тарифы»](../_files/billing/tariffs.png)


| | Бесплатный | Базовый | Энтерпрайз |
|---|---|---|---|
| **Цена** | 0 ₽/мес | 4 900 ₽/мес | по договору |
| **Паспортов / мес** | 5 | ∞ | по контракту |
| **Хранилище** | 250 МБ | ∞ | по контракту |
| **Каталог** | demo | полный | полный |
| **Размещение** | Серверы в РФ | Серверы в РФ | on-premise (Docker) |

- **Перейти на тариф** – переключение на выбранный тариф;
- **Текущий тариф** – план, на котором работает организация сейчас;
- **Запросить демо** – заявка на тариф «Энтерпрайз».

{% note info "" %}

Тариф «Энтерпрайз» подключается по договору: цена и условия согласуются отдельно.

{% endnote %}

## История

### Операции

Во вкладке отображаются пополнения и списания по балансу.

![Вкладка «История», субвкладка «Операции»](../_files/billing/history-operations.png)

### Счета

Во вкладке отображаются счета на оплату, которые появляются после пополнения баланса. Счета можно отфильтровать по статусу:

| Статус | Значение |
|---|---|
| Ожидает оплаты | счёт выставлен, оплата не поступила |
| Оплачен частично | поступила часть суммы |
| Оплачен | счёт оплачен полностью |
| Аннулирован | счёт отменён |
| Просрочен | оплата не поступила в срок |

![Вкладка «История», субвкладка «Счета»](../_files/billing/history-invoices.png)

## Акты

Во вкладке отображаются закрывающие документы за оплаченные расчётные периоды. Акт считается принятым, если в течение 5 рабочих дней с даты доступности не поступило мотивированных возражений.

Акт формируется после завершения каждого оплаченного расчётного периода. На бесплатном тарифе акты не выставляются.

![Вкладка «Акты»](../_files/billing/acts.png)
