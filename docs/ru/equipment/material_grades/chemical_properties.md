# Химические свойства

Химический состав материала одинаков для всех технологий изготовления и задается в блоке «Химические свойства» формы марки материала.

## Добавление химического свойства

![Добавление химического свойства](../../_images/chemical_properties_add.png)

1. В блоке «Химические свойства» нажмите **«Добавить свойство…»**.
2. В выпадающем списке выберите нужные химические элементы:
   - Алюминий (Al);
   - Ванадий (V);
   - Железо (Fe);
   - Кобальт (Co);
   - Кремний (Si);
   - Марганец (Mn);
   - Медь (Cu);
   - Молибден (Mo);
   - Никель (Ni);
   - Ниобий (Nb);
   - Сера (S);
   - Титан (Ti);
   - Углерод (C);
   - Фосфор (P);
   - Хром (Cr).
3. Укажите содержание элемента в процентах – отдельным значением, диапазоном или текстом, например:
   - `≤ 0.2 %` – не более;
   - `9 – 11 %` – диапазон значений;
   - `основа` – текст.

Добавленные свойства отображаются списком «элемент – значение». Чтобы удалить свойство, нажмите кнопку удаления напротив строки.

{% note info "" %}

Химический состав задается один раз и применяется ко всем технологиям изготовления марки.

{% endnote %}
