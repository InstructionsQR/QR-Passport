# Пневмоприводы

Для моделей с видом изделия **Пневмопривод** доступен отраслевой шаблон паспорта по [СТ ЦКБА 031-2015](https://meganorm.ru/Index2/1/4293763/4293763006.htm) и [ГОСТ Р 2.610-2016](https://meganorm.ru/Data/10/1092.pdf).

## Доступные шаблоны

- **Паспорт пневмопривода (РФ)** – содержит разделы и характеристики, необходимые для паспортизации пневмоприводов: поршневого типа, неполнооборотных, двустороннего действия и других.
