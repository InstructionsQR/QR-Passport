# Трубопроводная арматура

Для моделей с видом изделия **Трубопроводная арматура** доступны пять отраслевых шаблонов паспортов. Все они учитывают требования [ГОСТ 34612-2019](https://files.stroyinf.ru/Index/72/72322.htm) и [ГОСТ Р 2.610-2016](https://meganorm.ru/Data/10/1092.pdf), а также отраслевые требования отрасли поставки.

## Доступные шаблоны

- [Общепромышленный (РФ)](general_industrial.md) – базовый вариант для изделий общепромышленного применения;
- Общепромышленный, БС (РФ) – вариант без обязательной сертификации;
- Нефтяная и нефтехимическая промышленность (РФ) – учитывает требования нефтяных компаний («Роснефть», «Лукойл», «ИНК»);
- СТО 2.4.1-212-2008 Газпром (РФ) – для изделий, поставляемых на объекты ПАО «Газпром»;
- Атомные станции (РФ) – для изделий, поставляемых на атомные станции.

Выбор шаблона зависит от вида изделия, указанного при создании модели. Если выбран вид изделия **Трубопроводная арматура** – доступны пять отраслевых шаблонов, а если **Пневмопривод** – шаблон для пневмопривода.
