# Трубопроводная арматура

Для моделей с видом изделия **Трубопроводная арматура** доступны пять отраслевых шаблонов паспортов. Все они учитывают требования ГОСТ 34612-2019 и ГОСТ Р 2.610-2016, а также отраслевые требования отрасли поставки.

## Доступные шаблоны

- **Паспорт трубопроводной арматуры. Общепромышленный (РФ)** – базовый вариант для изделий общепромышленного применения;
- **Паспорт трубопроводной арматуры. Общепромышленный, БС (РФ)** – вариант без обязательной сертификации;
- **Паспорт трубопроводной арматуры. Нефтяная и нефтехимическая промышленность (РФ)** – учитывает требования нефтяных компаний («Роснефть», «Лукойл», «ИНК»);
- **Паспорт трубопроводной арматуры. СТО 2.4.1-212-2008 Газпром (РФ)** – для изделий, поставляемых на объекты ПАО «Газпром»;
- **Паспорт трубопроводной арматуры. Атомные станции (РФ)** – для изделий, поставляемых на атомные станции.
