# Паспорт качества ЖБИ

{% note tip %}

Для каждого шаблона можно скачать образец паспорта в PDF. Нажмите кнопку **«Скачать образец PDF»** в правом верхнем углу страницы шаблона – скачается пример заполненного документа для этого шаблона.

{% endnote %}

Шаблон предназначен для выпуска паспортов качества на бетонные и железобетонные изделия согласно [ГОСТ 13015-2012](https://files.stroyinf.ru/Data2/1/4293782/4293782273.pdf). Выберите этот шаблон, если ваша продукция относится к конструкциям из бетона или железобетона.

Структура шаблона гибкая: разделы **«Заметки по гарантии, эксплуатации и хранению»** и **«Особые отметки»** можно отключать, если они не нужны для конкретного типа продукции. Остальные блоки обязательны. Ниже описаны основные разделы, доступные в этом типе документов.

## Логотип

Графическое обозначение (товарный знак) изготовителя. Размещается в левой верхней части паспорта. Вы можете загрузить файл формата PNG или JPEG размером до 2 МБ.

## Основные сведения

Информация об организации-производителе, которая печатается в шапке документа.

- **Изготовитель: наименование и адрес** – полное юридическое название, ИНН, КПП, банковские реквизиты (при необходимости) и физический адрес предприятия. Эти данные вводятся вручную через кнопку **«Изменить»**.

## Основные технические данные

Ключевой блок паспорта, содержащий характеристики конкретной партии изделий. Реализован как динамическая таблица.

- Чтобы добавить строку, нажмите кнопку **«+ Строку»** в правом верхнем углу блока.
- Каждая строка состоит из двух полей: **Наименование параметра** (обязательное) и **Значение**.
- Строк может быть любое количество; система подсчитывает их автоматически (например, «11 строк»).

**Пример типовых параметров для ЖБИ:**

| Наименование параметра | Значение |
|---|---|
| Марка бетона по морозостойкости | F₂200 |
| Марка бетона по водонепроницаемости | W4 |

{% note info %}

Некоторые поля этой таблицы могут быть скрыты на публичной странице проверки (которую открывает конечный пользователь по QR-коду), но обязательно попадают в итоговый PDF-файл.

{% endnote %}

## Заметки по гарантии, эксплуатации и хранению

Текстовый блок для условий хранения, транспортирования и гарантийных обязательств. Поле свободное – вы можете редактировать текст под свои регламенты.

## Особые отметки

Дополнительное текстовое поле для важных примечаний, не попадающих в основные категории. Например: «Изделия отгружены с отпускной прочностью бетона не ниже нормируемой».

## Переменные параметры

Системные параметры, которые заполняются вручную на этапе регистрации конкретного изделия, а не в самом шаблоне. Они обеспечивают уникальность каждого паспорта.

- **Номер паспорта** – уникальный идентификатор документа.
- **Дата паспорта** – дата формирования или подписания документа.

{% note warning "Важно" %}

Все параметры, зафиксированные в настройках шаблона, копируются во все будущие изделия. Поэтому создавайте универсальный шаблон: индивидуальные значения (партия, даты и т.д.) оставляйте пустыми в шаблоне – они будут запрошены у оператора при нажатии кнопки **«Зарегистрировать изделие»**.

{% endnote %}
