# Быстрый старт

Раздел содержит пошаговую инструкцию по освоению основного процесса работы в системе QR-Passport – создания моделей оборудования и регистрации изделий.

## Порядок работы
Инструкция разделена на этапы, выполнение которых позволяет последовательно освоить функционал системы. Каждый этап содержит чёткие шаги и пояснения. Для начала работы рекомендуется ознакомиться с основными понятиями системы и перейти к тестовой модели.

Этапы выстроены в порядке наследования данных: сначала создается марка материала (источник химического и механического состава), затем сертификат с фактическими значениями для партии, деталь привязывается к марке и технологии, и только после этого собирается модель и регистрируются изделия.

## Основные понятия и процессы
* **Модель оборудования** –  карточка группы однотипных изделий. В ней хранятся общие характеристики, шаблоны паспортов и документация для всех изделий этой группы.

* **Шаблоны изделий** – готовые шаблоны паспортов, которые содержат основные разделы/подразделы и характеристики в соответствии с отраслевыми и нормативными документами.

{% note info "Примечания" %}

На данный момент в QR-Passport заведены пять отраслевых шаблонов для трубопроводной арматуры в соответствии с ГОСТ 34612-2019, ГОСТ Р 2.610-2016, а также с учетом отраслевых требований:
   * _общепромышленный_;
   * _общепромышленный (БС)_ – вариант без обязательной сертификации;
   * _нефтяная отрасль_ – выполнен с учетом требований «Роснефти», «Лукойла», «ИНК»;
   * _газовая отрасль_ – выполнен с учетом требований «Газпрома»;
   * _атомная отрасль_ – выполнен с учетом требований «Росатома».

{% endnote %}

* **Данные изделия** – настраиваемые характеристики, которые добавляются к модели и заполняются для каждого изделия отдельно. Позволяют учитывать индивидуальные особенности разных единиц оборудования, такие как заводской номер и дата изготовления.

* **Зарегистрировать изделие** – внести в систему данные о конкретной единице продукции, включая заполнение данных изделия. В результате изделие получает собственный QR-код и становится полноценным объектом учета в системе с возможностью отслеживания актуальности документации – то есть **_зарегистрированным изделием_**.

## Тестовая модель
### Описание

**_Задача:_** _выпустить 5 паспортов на трубопроводную арматуру (дисковый затвор – Затвор ЗД-100) с серийными номерами: ЗД-001-2026 – ЗД-005-2026 от 02.02.2026._

Для примера зададим этому затвору такие характеристики:
- Группа – _Дисковые затворы_.
- Модель затвора – _Затвор ЗД-100_ с параметрами:
    * _DN = 100;_
    * _PN = 10 МПа;_
    * _Тип присоединения – фланцевый;_
    * _Способ управления – ручной (маховик);_
    * _Материал корпуса – 08Х18Н10Т._    

## Шаги выполнения
### Марка материалов
Марка материала – источник химического состава и механических свойств: детали и сертификаты будут наследовать эти данные. В первую очередь необходимо создать марку материала корпуса — 08Х18Н10Т. Для этого выполните следующие шаги:

1. Перейдите в раздел **Марки материалов**.
2. Нажмите кнопку **Добавить марку**.
3. Введите название марки – `08Х18Н10Т`.
4. Введите название нормативного документа (далее – НД), где описаны параметры этой марки – `ТУ 14-3Р-197-2001`.
5. Затем переписываем химический состав этой марки из НД.
6. Переписываем механические свойства этой марки из НД.
7. Нажмите кнопку **Сохранить**.

### Сертификаты
Сертификат хранит фактические (измеренные) значения свойств для конкретной партии/плавки материала. Далее приступаем к добавлению сертификата. Для этого выполните следующие шаги:

8. Перейдите в раздел **Сертификаты**.
9. Нажмите кнопку **Добавить сертификат**.
10. Введите название сертификата – `12501-03`.
11. Прикрепите документ – для тестовой модели используйте этот [сертификат](https://drive.google.com/file/d/1k1JICkHH7NllwAIMN5Knjx--m0q1d6O_/view?usp=drive_link).
12. Нажмите кнопку **Добавить первую партию**.
13. Введите название партии/плавки – `626331`.
14. Выберите из выпадающего списка ранее созданную марку материала – **08Х18Н10Т**.
15. Заполните химические и механические свойства из примера, взятые из сертификата 12501-03.
16. Нажмите кнопку **Сохранить**.

### Детали
Деталь связывает модель с маркой материала и технологией изготовления – через неё изделие получает свойства. Далее приступаем к добавлению детали. Для этого выполните следующие шаги:

17. Перейдите в раздел **Детали**.
18. Нажмите кнопку **Создать деталь**.
19. Введите название детали – `Корпус затвора ЗД-100`.
20. Введите обозначение детали – `РМТМ.123456.001`.
21. Выберите из выпадающего списка ранее созданную марку материала – **08Х18Н10Т**.
22. Выберите из выпадающего списка ранее созданную технологию изготовления – **Закалка 1100°С-1170°С (ВЗ, М)**.
23. Нажмите кнопку **Создать**.

### Модели
Далее создадим структуру оборудования – группу и модель внутри неё, чтобы классифицировать изделие. Для этого выполните следующие шаги:

24. Перейдите в раздел **Модели**. 
25. Нажмите кнопку **Создать группу**.
26. Введите название группы `Дисковые затворы` – это название типа оборудования, и его удобно взять за основу структуры.
27. Нажмите кнопку **Создать**.

{% cut "см. шаги 24-27" %}

![24-27](./_images/example_24-27.png)

{% endcut %}

Далее создаем модель внутри группы. Для этого выполните следующие шаги:

28. Нажмите кнопку **Добавить модель**.
29. Введите название модели – `Затвор ЗД-100`.
30. Выберите из выпадающего списка ранее созданную группу – **Дисковые затворы**.
31. Выберите из выпадающего списка вид изделия – **Трубопроводная арматура**.
32. Выберите из выпадающего списка тип элемента – **Затвор дисковый**.
33. Введите параметр DN – `100`.
34. Введите параметр PN – `10 МПа`.
35. Выберите из выпадающего списка тип присоединения – **Фланцевый**.
36. Выберите из выпадающего списка способ управления – **Ручной (маховик)**.
37. Выберите из выпадающего списка ранее созданную марку материала – **08Х18Н10Т**.
38. Прикрепите документ – для тестовой модели используйте пример этого [руководства](https://drive.google.com/file/d/1BB-MYdtWLJB3HJBXKpRWWGC8fPpekw5f/view?usp=drive_link).
39. Нажмите кнопку **Создать модель**.

40. Загрузите изображение модели – для тестовой модели используйте это [изображение](https://drive.google.com/file/d/11JsryoYYE20jrbBBgLel5rSd8w_YOPDx/view?usp=drive_link).

Далее необходимо выбрать нужный шаблон паспорта для нашей модели. Для примера возьмем «Паспорт трубопроводной арматуры. Общепромышленный, (РФ)». Для этого выполните следующие шаги:

41. Перейдите во вкладку **Шаблоны**.
42. Нажмите кнопку **Добавить другой шаблон**.
43. В появившемся окне выберите из списка шаблон – **Паспорт трубопроводной арматуры. Общепромышленный, (РФ)**.
44. Заполните обязательные поля, отмеченные звёздочкой:
    - Титульный лист: прикрепите логотип – для тестовой модели используйте этот [логотип](https://drive.google.com/file/d/1zne6BVwaOCY1q1adzlxvl8zk4YHeafTP/view?usp=drive_link).
    - Титульный лист: введите наименование изделия – `Затвор ЗД-100` → нажмите ниже **Готово**;
    - Титульный лист: введите обозначение паспорта – `РМТМ.123456.001 ПС`→ нажмите ниже **Готово**.
    - Основные сведения: введите изготовителя – `ООО «ПИК АЙТИ», Свердловская область, г. Екатеринбург`.
    - Отключите раздел **Привод** переключателем, т.к. управление затвором – ручное.
    - Материалы основных деталей: Химический состав
        * нажмите **+ строку** слева; 
        * выберите созданную деталь **Корпус затвора ЗД…**;
        * выберите ранее созданный сертификат **12501-03**.
    - Материалы основных деталей: Механические свойства
        * нажмите **+ строку** слева; 
        * выберите созданную деталь **Корпус затвора ЗД…**;
        * выберите ранее созданный сертификат **12501-03**.
    - Вид контроля: введите `Визуальный` → отметка ОТК: введите `Полное соответствие КД`.
    - Данные приёмо-сдаточных испытаний
        * нажмите **+ строку** слева; 
        * введите наименование `Затвор ЗД-100` → введите вид испытаний `Герметичность затвора`.
    - Комплектность: 
        * введите наименование `Затвор ЗД-100` → обозначение: введите `РМТМ.123456.001` → количество: 1;
        * введите наименование `Паспорт` → обозначение: введите `РМТМ.123456.001 ПС` → количество: 1;
        * введите наименование `Руководство по эксплуатации` → обозначение: введите `РМТМ.123456.001 РЭ` → количество: 1.
    - Отключите раздел **Разрешенные отклонения** переключателем.
    - Отключите раздел **Дополнительные сведения** переключателем.
45. Убедитесь, что все обязательные поля заполнены и нажмите кнопку **Сохранить**.
46. Подтвердите изменения, нажмите кнопку **Подтвердить**.

### Зарегистрированные изделия

Заключительный этап – регистрация изделия: система выпустит серию с серийными номерами и сгенерирует QR-коды. Для этого выполните следующие шаги:

47. Вернитесь на предыдущую вкладку **Затвор ЗД-100**.
48. Нажмите кнопку **Зарегистрировать изделие**.
49. Проверьте введенные данные и нажмите кнопку **Далее**.
50. Перейдите во вкладку **Серия изделий**.
51. Заполните поля:
    * Префикс – **ЗД-**;
    * Стартовый номер – **001**;
    * Шаг – оставляем 1;
    * Суффикс – **-2026**;
    * Количество – **5**;
    * Дата изготовления (поставки) – **02.02.2026**.
52. Нажмите кнопку **Далее**.
53. Заполните все обязательные даты, например, датой **02.02.2026**.
54. Нажмите кнопку **Зарегистрировать 5 изделий**.

## Результат

Основные возможности системы QR-Passport изучены. Для перехода к реальной эксплуатации системы необходимо выполнить следующие действия:

1. _Удаление зарегистрированных изделий_
   - Перейдите в раздел **Зарегистрированные изделия**.
   - Галочками выберите серийные номера изделий (**ЗД-001-2026** – **ЗД-005-2026**).
   - Нажмите кнопку **Удалить**.
   - Подтвердите удаление словом **Удалить**.
   - Нажмите **Удалить 5 изделий**.

2. _Удаление шаблона_
   - Перейдите в раздел **Модели**.
   - Перейдите во вкладку **Шаблоны**.
   - Нажмите **...** справа.
   - Выберите **Удалить шаблон**.
   - Нажмите **Удалить шаблон**.

3. _Удаление модели_
   - Перейдите в раздел **Модели**.
   - Выберите модель **Затвор ЗД-100**.
   - Нажмите **...** справа.
   - Выберите **Удалить**.
   - Нажмите **Удалить модель**. 

4. _Удаление группы_
    - В разделе **Модели** напротив группы нажмите **...** справа.
    - Выберите **Удалить**.
    - Нажмите **Удалить группу**.    

5. _Дальнейшие действия_
    - Изучите остальные разделы инструкции.
    - Приступите к созданию рабочих моделей и регистрации оборудования для повседневной эксплуатации.
