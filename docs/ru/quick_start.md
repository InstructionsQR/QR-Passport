# Быстрый старт

Раздел содержит пошаговую инструкцию по освоению основного процесса работы в системе QR-Passport – создание моделей оборудования и регистрация изделий.

## Порядок работы
Инструкция разделена на этапы, выполнение которых позволяет последовательно освоить функционал системы. Каждый этап содержит четкие шаги и пояснения. Для начала работы рекомендуется ознакомиться с основными понятиями системы и перейти к тестовой модели.

## Основные понятия и процессы
* **Модель оборудования** –  это модель для группы однотипных изделий. Она содержит общие характеристики, шаблоны, документацию для всех относящихся к нему изделий.

* **Шаблоны изделий** – готовые шаблоны для паспортов, которые содержат основные разделы/подразделы и характеристики в соответствии с отраслевыми и нормативными документами.

{% note info "Примечания" %}

На данный момент в QR-Passport заведены пять отраслевых шаблонов для трубопроводной арматуры в соответствии с ГОСТ 34612-2019, ГОСТ Р 2.610-2016, а также с учётом отраслевых требований:
   * _общепромышленный_;
   * _нефтяная отрасль_ – выполнен с учётом требований «Роснефти», «Лукойла», «ИНК»;
   * _газовая отрасль_ – выполнен с учётом требований «Газпрома»;
   * _атомная отрасль_ – выполнен с учётом требований «Росатома».

{% endnote %}

* **Данные изделия** – настраиваемые характеристики, которые добавляются к модели и заполняются для каждого изделия отдельно. Позволяют учитывать индивидуальные особенности разных единиц оборудования, такие как: заводской номер и дата изготовления.

* **Зарегистрировать изделие** – это процесс внесения в систему данных о конкретной единице продукции, который включает заполнение данных изделия. В результате изделие получает собственный QR-код и становится полноценным объектом учета в системе с возможностью отслеживания актуальности документации, т.е. **_зарегистрированным изделием_**.

## Активные элементы в инструкции
В инструкции используются активные элементы. Ниже приведены примеры таких элементов и пояснения, как с ними работать.

{% note info "Примечания" %}

* **_Текст для копирования_** – чтобы не вводить текст вручную, используйте элементы голубого цвета. Например: «_Введите название группы_ `Дисковые затворы`». Кликните на элемент `Дисковые затворы` и текст скопируется в буфер обмена (без визуального подтверждения), после чего вы можете вставить его в нужное поле.

* **_Ссылки для скачивания_** – в разделе есть активные ссылки для скачивания файлов, выглядят они так: «_Прикрепите документ – для тестовой модели используйте этот [документ] [1]._». Нажмите на ссылку [документ] [1], чтобы скачать файл для тестовой модели.

## Тестовая модель
### Описание

**_Задача: выпустить 5 паспортов на трубопроводную арматуру (дисковый затвор – Затвор ЗД-100) с серийными номерами: ЗД-001-2026 – ЗД-005-2026 от 02.02.2026_**

Для примера зададим этому затвору такие характеристики:
- Группа – _Дисковые затворы_.
- Модель затвора – _Затвор ЗД-100_ с параметрами:
    * _DN = 100;_
    * _PN = 10 МПа;_
    * _Тип присоединения – фланцевый;_
    * _Способ управления – ручной (маховик);_
    * _Материал корпуса – 08Х18Н10Т._    

## Шаги выполнения
### Марка материалов
В первую очередь необходимо создать марку материала корпуса – 08Х18Н10Т. Для этого выполните следующие шаги:

1. Перейдите в раздел **Марки материалов**.
2. Нажмите кнопку **Добавить марку**.
3. Введите название марки – `08Х18Н10Т`.
4. Введите название нормативного документа (далее – НД), где описаны параметры этой марки – `ТУ 14-3Р-197-2001`.
5. Затем переписываем химический состав этой марки из НД.
6. Переписываем механические свойства этой марки из НД.
7. Нажмите кнопку **Сохранить**.

### Сертификаты
Далее приступаем к добавлению сертификата. Для этого выполните следующие шаги:

8. Перейдите в раздел **Сертификаты**.
9. Нажмите кнопку **Добавить сертификат**.
10. Введите название сертификата – `12501-03`.
11. Прикрепите документ – для тестовой модели используйте этот [документ] [1].
12. Нажмите кнопку **Добавить первую партию**.
13. Введите название партии/плавки – `626331`.
14. Выберите из выпадающего списка ранее созданую марку материала – **08Х18Н10Т**.
15. Заполните химические и механические свойства как в примере (якобы, взятые из сертификата 12501-03).
16. Нажмите кнопку **Сохранить**.

### Детали
Далее приступаем к добавлению детали. Для этого выполните следующие шаги:

17. Перейдите в раздел **Детали**.
18. Нажмите кнопку **Создать деталь**.
19. Введите название детали – `Корпус затвора ЗД-100`.
20. Введите обозначение детали – `РМТМ.123456.001`.
21. Выберите из выпадающего списка ранее созданую марку материала – **08Х18Н10Т**.
22. Выберите из выпадающего списка ранее созданую технологию изготовления – **Закалка 1100°С-1170°С (ВЗ, М)**.
23. Нажмите кнопку **Создать**.

### Модели
Далее создаем структуру оборудования. Для того, чтобы классифицировать созданное изделие. 
Для этого выполните следующие шаги:

24. Перейдите в раздел **Модели**. 
25. Нажмите кнопку **Создать группу**.
26. Введите название группы `Дисковые затворы` – так назовем группу, т.к. это название оборудования и его можно взять за основу структуры.
27. Нажмите кнопку **Создать**.

{% cut "см. шаги 24-27" %}

![24-27](./_images/example_24-27.png)

{% endcut %}

Далее создаем модель внутри созданной группы. Для этого выполните следующие шаги:

28. Нажмите кнопку **Добавить модель**.
29. Введите название модели – `Затвор ЗД-100`.
30. Выберите из выпадающего списка ранее созданую группу – **Дисковые затворы**.
31. Выберите из выпадающего списка вид изделия – **Трубопроводная арматура**.
32. Выберите из выпадающего списка тип элемента – **Затвор дисковый**.
33. Введите параметр DN – `100`.
34. Введите параметр PN – `10 МПа`.
35. Выберите из выпадающего списка тип присоединения – **Фланцевый**.
36. Выберите из выпадающего списка способ управления – **Ручной (маховик)**.
37. Выберите из выпадающего списка ранее созданую марку материала – **08Х18Н10Т**.
38. Прикрепите документ – для тестовой модели используйте пример этого руководства [документ] [2].
39. Нажмите кнопку **Создать модель**.
 
{% cut "см. шаги 28-39" %}

![28](./_images/example_28.png)
![29-39](./_images/example_29-39.png)

{% endcut %}

40. Загрузите изображение модели – для тестовой модели используйте этот [документ] [3].

Далее необходимо выбрать нужный шаблон паспорта для нашей модели. Для примера возьмем – Паспорт трубопроводной арматуры. Общепромышленный, (РФ). Для этого выполните следующие шаги:

41. Перейдите во вкладку **Шаблоны**.
42. Нажмите кнопку **Добавить другой шаблон**.
43. В появившемся окне выберите из списка шаблон – **Паспорт трубопроводной арматуры. Общепромышленный, (РФ)**.
44. Заполните обязательные поля, отмеченные звёздочкой:
    - Титульный лист: прикрепите логотип – для тестовой модели используйте этот [документ] [4].
    - Титульный лист: введите наименование изделия – `Затвор ЗД-100` → нажмите ниже **Готово**;
    - Титульный лист: введите обозначение паспорта – `РМТМ.123456.001 ПС`→ нажмите ниже **Готово**.
    - Основные сведения: введите изготовителя – `ООО «ПИК АЙТИ», Свердловская область, г. Екатеринбург`.
    - Отключите раздел **Привод** переключателем, т.к. управление затвором – ручное.
    - Материалы основных деталей: Химический состав
        * нажмите **+ строку** слева; 
        * выберите созданную деталь **Корпус затвора ЗД…**;
        * выберите ранее созданный сертификат **12501-03**.
    - Материалы основных деталей: Механические свойства
        * нажмите **+ строку** слева; 
        * выберите созданную деталь **Корпус затвора ЗД…**;
        * выберите ранее созданный сертификат **12501-03**.
    - Вид контроля: введите `Визуальный` → отметка ОТК: введите `Полное соответствие КД`.
    - Данные приёмо-сдаточных испытаний
        * нажмите **+ строку** слева; 
        * введите наименование `Затвор ЗД-100` → введите вид испытаний `Герметичность затвора`.
    - Комплектность: 
        * введите наименование `Затвор ЗД-100` → обозначение: введите `РМТМ.123456.001` → количество: 1;
        * введите наименование `Паспорт` → обозначение: введите `РМТМ.123456.001 ПС` → количество: 1;
        * введите наименование `Руководство по эксплуатации` → обозначение: введите `РМТМ.123456.001 РЭ` → количество: 1.
    - Отключите раздел **Разрешенные отклонения** переключателем.
    - Отключите раздел **Дополнительные сведения** переключателем.
45. Убедитесь, что все обязательные поля заполнены и нажмите кнопку **Сохранить**.
46. Подтвердите изменения, нажмите кнопку **Подтвердить**.

### Зарегистрированные изделия

Заключительный этап – это регистрация изделия. Для этого выполните следующие шаги:

47. Вернитесь на предыдущую вкладку **Затвор ЗД-100**.
48. Нажмите кнопку **Зарегистрировать изделие**.
49. Проверьте введенные данные и нажмите кнопку **Далее**.
50. Перейдите во вкладку **Серия изделий**.
51. Заполните поля:
    * Префикс – **ЗД-**;
    * Стартовый номер – **001**;
    * Шаг – оставляем 1;
    * Суффикс – **-2026**;
    * Количество – **5**;
    * Дата изготовления (поставки) – **02.02.2026**.
52. Нажмите кнопку **Далее**.
53. Заполните все обязательные даты, например, датой **02.02.2026**.
54. Нажмите кнопку **Зарегистрировать 5 изделий**.

## Результат

Основные возможности системы QR-Passport изучены. Для перехода к реальной эксплуатации системы необходимо выполнить следующие действия:

1. _Удаление зарегистрированных изделий_
   - Перейдите в раздел **Зарегистрированные изделия**.
   - Галочками выберите серийные номера изделий (**ЗД-001-2026** – **ЗД-005-2026**).
   - Нажмите кнопку **Удалить**.
   - Подтвердите удаление словом **Удалить**.
   - Нажмите **Удалить 5 изделий**.

2. _Удаление шаблона_
   - Перейдите в раздел **Модели**.
   - Перейдите во вкладку **Шаблоны**.
   - Нажмите **...** справа.
   - Выберите **Удалить шаблон**.
   - Нажмите **Удалить шаблон**.

3. _Удаление модели_
   - Перейдите в раздел **Модели**.
   - Выберите модель **Затвор ЗД-100**.
   - Нажмите **...** справа.
   - Выберите **Удалить**.
   - Нажмите **Удалить модель**. 

4. _Удаление группы_
    - Во разделе **Модели** напротив группы нажмите **...** справа.
    - Выберите **Удалить**.
    - Нажмите **Удалить группу**.    

5. _Дальнейшие действия_
    - Изучите остальные разделы инструкции.
    - Приступите к созданию рабочих моделей и регистрации оборудования для повседневной эксплуатации.
