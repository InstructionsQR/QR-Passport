# Часто задаваемые вопросы

## Обучение

{% cut "_С чего начать: Практическое руководство или Быстрый старт?_" %}

Зависит от вашего вида изделия:

- **Трубопроводная арматура** – начните с [Практического руководства](quick_start.md). Оно построено на полном цикле: марка материала → сертификат → деталь → модель → шаблон → регистрация.
- **Пневмоприводы, электроприводы и другое оборудование** – используйте [Быстрый старт](quick_start_other.md). Путь там короче: модель → шаблон → регистрация → подпись → скачивание. В примере используется редуктор.
- **Бетонные и железобетонные изделия (ЖБИ)** – процесс похож на «Быстрый старт», но имеет свои нюансы (заполнение таблицы параметров бетона, привязка к партии). Читайте пошаговый алгоритм и описание полей в подразделе [Паспорт качества](\equipment\models\templates\quality_passport.md).

Оба основных раздела доводят до скачивания паспортов и QR-кодов пошагово.

{% endcut %}


## Работа с данными

{% cut "_В каком порядке создавать данные в QR-Passport?_" %}

Для **трубопроводной арматуры**: сначала марка материала, потом сертификат с партией, затем деталь, потом модель и в конце – регистрация изделия. Это порядок наследования: каждый следующий объект использует данные предыдущих.

Для **пневмоприводов, электроприводов, другого оборудования и ЖБИ** путь короче: создайте модель → настройте шаблон паспорта → зарегистрируйте изделие. Пошаговый пример – в разделе «Быстрый старт».

{% endcut %}

{% cut "_Почему для моего изделия не нужны марки материалов, сертификаты и детали?_" %}

Эти объекты участвуют только в работе с **трубопроводной арматурой**: паспорт подтягивает данные материалов из марки и сертификата. Для **пневмоприводов, электроприводов, другого оборудования и ЖБИ** цепочка начинается сразу с модели – система не требует марки материалов, сертификаты и детали для этих видов изделий.

{% endcut %}

{% cut "_Можно ли удалить марку материала, если она уже используется?_" %}

Нет. Сначала удалите все детали, сертификаты, где эта марка используется, – только потом можно удалить саму марку. Общий принцип: удаляем в обратном порядке относительно создания.

{% endcut %}

{% cut "_Почему нельзя сразу удалить модель или марку материала?_" %}

Система защищает связанные данные: пока по модели зарегистрированы изделия или настроены шаблоны, удалить её нельзя – сначала удалите зависимые объекты. То же с маркой материала: пока её используют детали и сертификаты, марка остаётся в системе. Порядок удаления – обратный порядку создания: изделия – шаблон – модель; детали и сертификаты – марка.

{% endcut %}

## Модели

{% cut "_Чем модель отличается от зарегистрированного изделия?_" %}

Модель – описание группы однотипных изделий: в ней хранятся общие характеристики, шаблоны паспортов и документы. Зарегистрированное изделие – конкретная единица продукции с собственным серийным номером, QR-кодом и паспортом. По одной модели можно зарегистрировать много изделий.

{% endcut %}

{% cut "_Что такое группа моделей и обязательна ли она?_" %}

Группа – это визуальная папка для моделей, помогает ориентироваться, когда моделей много. Она необязательна: модели без группы отображаются в разделе «– БЕЗ ГРУППЫ –».

{% endcut %}

{% cut "_Зачем клонировать модель?_" %}

Если у вас линейка однотипных изделий, один раз заполните модель и шаблон, а дальше клонируйте их – останется только зарегистрировать изделия. Это заметно ускоряет работу.

{% endcut %}

{% cut "_Что копируется при клонировании модели?_" %}

Характеристики модели и, по вашему выбору, шаблоны изделий: у шаблонов копируются L2-настройки (описания, изображения, гарантия и др.). Наименование новой модели вводится вручную. Не копируются сертификаты соответствия и приложенные документы шаблона – их нужно загрузить заново на странице нового шаблона.

{% endcut %}

## Шаблоны и паспорта

{% cut "_Что такое шаблон паспорта?_" %}

Шаблон – готовая структура паспорта с разделами и характеристиками в соответствии с отраслевыми и нормативными документами. Шаблон привязывается к модели, и изделия регистрируются по нему.

{% endcut %}

{% cut "_Какие отраслевые шаблоны уже есть в системе?_" %}

Для трубопроводной арматуры доступны пять шаблонов: общепромышленный, общепромышленный (БС), нефтяная и нефтехимическая промышленность, газовая и атомная отрасль.

Для пневмоприводов доступен шаблон «Паспорт пневмопривода (РФ)» по СТ ЦКБА 031-2015 и ГОСТ Р 2.610-2019.

Для электроприводов доступен шаблон «Паспорт электропривода (РФ)» по ГОСТ 34610-2019 и ГОСТ Р 2.610-2019.

Для любого другого оборудования доступен общий шаблон «Паспорт изделия (РФ)» по ГОСТ Р 2.610-2019.

Для бетонных и железобетонных изделий доступен специализированный шаблон «Паспорт качества ЖБИ» по ГОСТ 13015-2012.

{% endcut %}

{% cut "_Можно ли к одной модели привязать несколько шаблонов?_" %}

Да. Например, для трубопроводной арматуры можно привязать один шаблон для общепромышленных поставок и отдельный – для атомной отрасли. Паспорта будут выпускаться по каждому шаблону отдельно.

Для пневмоприводов, электроприводов и ЖБИ по умолчанию доступен один шаблон, поэтому несколько шаблонов актуально именно для трубопроводной арматуры.

{% endcut %}

{% cut "_Обязательно ли заполнять все разделы шаблона?_" %}

Нет, необязательно. Разделы, которые не применяются к изделию (например, «Привод» при ручном управлении), отключаются переключателем.

{% endcut %}

{% cut "_Что произойдёт, если изменить шаблон паспорта?_" %}

Измененный шаблон будет применяться к изделиям, зарегистрированным после изменения. Уже зарегистрированные изделия останутся с теми данными, с которыми они были зарегистрированы, – их паспорта не изменятся.

{% endcut %}

{% cut "_Что значит поле с прочерком «–» в паспорте?_" %}

Так отображаются поля, которые вы не заполнили. Их можно заполнить позже или отключить в шаблоне, если они не нужны.

{% endcut %}

## Подпись ОТК

{% cut "_Что такое подпись ОТК и зачем она нужна?_" %}

Подпись ОТК (отдела технического контроля) – это финальный этап выпуска паспорта. Без неё документ считается черновиком: PDF и QR-код недоступны для скачивания.

Когда сотрудник ОТК проверяет данные и нажимает кнопку **«Подписать»**, система фиксирует факт проверки, добавляет строку ОТК в паспорт (должность, личная подпись, расшифровка, дата) и меняет статус изделия на **«Выпущен»**. Только после этого паспорт можно будет скачать.

{% endcut %}

{% cut "_Можно ли изменить данные после подписи ОТК?_" %}

Нет. После нажатия кнопки **«Подписать»** паспорт становится неизменяемым: статус меняется на **«Выпущен»**, а PDF и QR-код фиксируются как финальные документы.

{% endcut %}

{% cut "_Что делать, если паспорт возвращён?_" %}

Если сотрудник ОТК обнаружил ошибку, он нажимает кнопку **«Вернуть»** и указывает причину. Статус изделия изменится на **«Возвращён»**. Ответственный исполнитель увидит причину возврата в карточке изделия, отредактирует данные и повторно отправит документ на подпись.

{% endcut %}

## Изделия и QR-коды

{% cut "_Сколько изделий можно зарегистрировать за один раз?_" %}

В режиме «Серия изделий» – до 250 штук за одну регистрацию. Для единичного изделия используйте режим «Одно изделие».

{% endcut %}

{% cut "_Можно ли изменить уже зарегистрированное изделие?_" %}

Нет. Зарегистрированное изделие остается таким, каким оно было в момент регистрации: серийный номер, дата и данные паспорта не редактируются. Если в данных обнаружилась ошибка – удалите изделие и зарегистрируйте его заново.

{% endcut %}

{% cut "_Что видит клиент, отсканировав QR-код?_" %}

Публичную страницу паспорта: статус «Паспорт действителен», модель, серийный номер, дату регистрации, изображение изделия и документы модели. Вход в систему для этого не нужен.

{% endcut %}

{% cut "_В каком формате скачиваются паспорта и QR-коды?_" %}

Паспорта – в PDF. QR-коды – в PNG, SVG или PDF. Можно скачать их отдельно или вместе.

{% endcut %}
