# Часто задаваемые вопросы
## Работа с данными

{% cut "_В каком порядке создавать данные в QR-Passport?_" %}

Сначала марка материала, потом сертификат с партией, затем деталь, потом модель и в конце – регистрация изделия. Это порядок наследования: каждый следующий объект использует данные предыдущих.

{% endcut %}

{% cut "_Можно ли удалить марку материала, если она уже используется?_" %}

Нет. Сначала удалите все детали, сертификаты, где эта марка используется, – только потом можно удалить саму марку. Общий принцип: удаляем в обратном порядке относительно создания.

{% endcut %}

{% cut "_Что такое группа моделей и обязательна ли она?_" %}

Группа – это визуальная папка для моделей, помогает ориентироваться, когда моделей много. Она необязательна: модели без группы отображаются в разделе «– БЕЗ ГРУППЫ –».

{% endcut %}

## Шаблоны и паспорта

{% cut "_Какие отраслевые шаблоны уже есть в системе?_" %}

Для трубопроводной арматуры доступны пять шаблонов: общепромышленный, общепромышленный (БС), нефтяная и нефтехимическая промышленность, газовая и атомная отрасль.

{% endcut %}

{% cut "_Можно ли к одной модели привязать несколько шаблонов?_" %}

Да, например один шаблон для общепромышленных поставок и отдельный – для атомной отрасли. Паспорта будут выпускаться по каждому шаблону отдельно.

{% endcut %}

{% cut "_Обязательно ли заполнять все разделы шаблона?_" %}

Нет, необязательно. Разделы, которые не применяются к изделию (например, «Привод» при ручном управлении), отключаются переключателем.

{% endcut %}

{% cut "_Что значит поле с прочерком «–» в паспорте?_" %}

Так отображаются поля, которые вы не заполнили. Их можно заполнить позже или отключить в шаблоне, если они не нужны.

{% endcut %}

{% cut "_Зачем клонировать модель?_" %}

Если у вас линейка однотипных изделий, один раз заполните модель и шаблон, а дальше клонируйте их – останется только зарегистрировать изделия. Это заметно ускоряет работу.

{% endcut %}

## Изделия и QR-коды

{% cut "_Сколько изделий можно зарегистрировать за один раз?_" %}

В режиме «Серия изделий» – до 250 штук за одну регистрацию. Для единичного изделия используйте режим «Одно изделие».

{% endcut %}

{% cut "_Что видит клиент, отсканировав QR-код?_" %}

Публичную страницу паспорта: статус «Паспорт действителен», модель, серийный номер, дату регистрации, изображение изделия и документы модели. Вход в систему для этого не нужен.

{% endcut %}

{% cut "_В каком формате скачиваются паспорта и QR-коды?_" %}

Паспорта – в PDF. QR-коды – в PNG, SVG или PDF. Можно скачать их отдельно или вместе.

{% endcut %}
