# Основные понятия

Здесь собраны главные термины QR-Passport. Они помогут разобраться, как устроена система, перед переходом к [Практическому руководству](quick_start.md).

Понятия приведены в порядке наследования данных – от марки материала до зарегистрированного изделия.

* **Марка материала** – источник химического состава и механических свойств материала. К марке привязываются детали и сертификаты, которые наследуют эти данные.

* **Сертификат** – документ с фактическими (измеренными) значениями свойств для конкретной партии/плавки материала. Добавляется к марке материала.

* **Деталь** – составная часть изделия. Связывает модель с маркой материала и технологией изготовления – через неё изделие получает свойства.

* **Модель оборудования** – описание группы однотипных изделий. В ней хранятся общие характеристики, шаблоны паспортов и документация для всех изделий этой группы.

{% note info "Примечание" %}

Модель не является конкретным изделием. На основе модели регистрируются изделия, каждое из которых получает собственный серийный номер.

{% endnote %}

* **Группа моделей** – визуальное объединение моделей, например по типу оборудования. На характеристики изделий не влияет.

* **Шаблон паспорта** – определяет структуру паспорта в соответствии с отраслевыми и нормативными документами: его разделы, подразделы, характеристики и другие данные, которые должны быть указаны в документе.

{% note info "Примечание" %}

На данный момент в QR-Passport заведены пять шаблонов для трубопроводной арматуры в соответствии с ГОСТ 34612-2019, ГОСТ Р 2.610-2016, а также с учетом отраслевых требований:
   * _общепромышленный_;
   * _общепромышленный (БС)_ – вариант без обязательной сертификации;
   * _нефтяная отрасль_ – выполнен с учетом требований «Роснефти», «Лукойла», «ИНК»;
   * _газовая отрасль_ – выполнен с учетом требований «Газпрома»;
   * _атомная отрасль_ – выполнен с учетом требований «Росатома».

{% endnote %}

* **Данные изделия** – настраиваемые характеристики, которые добавляются к модели и заполняются для каждого изделия отдельно. Позволяют учитывать индивидуальные особенности разных единиц оборудования, такие как заводской номер и дата изготовления.

* **Зарегистрированное изделие** – конкретная единица продукции, зарегистрированная в QR-Passport. В результате регистрации изделие получает собственный QR-код и становится полноценным объектом учета с возможностью отслеживания актуальности документации.
