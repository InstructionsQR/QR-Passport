# Типовые ошибки и решения

На этой странице собраны частые ситуации и шаги по их устранению. Если вашей ошибки нет в списке – напишите в [поддержку](about.md#техническая-поддержка).

## При регистрации изделия

{% cut "_Не удаётся зарегистрировать изделие_" %}

**Причина:** не заполнены обязательные поля.

**Что делать:** на шаге 3 регистрации откройте блок «Соответствие». Все незаполненные поля перечислены списком – заполните их и повторите регистрацию.

{% endcut %}

{% cut "_Неактивна кнопка регистрации_" %}

**Причина:** не пройдена проверка обязательных полей.

**Что делать:** блок «Соответствие» должен быть зелёным и показывать «Все обязательные поля заполнены, отклонений не обнаружено». Пока в нём есть красные пункты, кнопка регистрации остаётся неактивной.

{% endcut %}

## При работе с моделями и шаблонами

{% cut "_Не удаётся удалить модель_" %}

**Причина:** у модели есть зарегистрированные изделия или настроенные шаблоны.

**Что делать:** удалите связанные объекты в обратном порядке: сначала изделия по модели, затем её шаблон, затем саму модель. Тот же принцип работает для марки материала: сначала детали и сертификаты, затем марка.

{% endcut %}

{% cut "_Шаблон паспорта не сохраняется_" %}

**Причина:** не заполнены поля, отмеченные звёздочкой.

**Что делать:** вернитесь к подсвеченным полям и заполните их. Система не сохраняет шаблон, пока есть незаполненные обязательные значения.

{% endcut %}

## Общие вопросы

{% cut "_Не удаётся прикрепить файл_" %}

**Причина:** неподходящий формат или размер больше 50 МБ.

**Что делать:** проверьте формат – PDF, DOC, DOCX, XLS, XLSX. Если файл больше 50 МБ, сожмите его или разделите на части и прикрепите каждую отдельно.

{% endcut %}
