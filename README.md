# Инструкция пользователя QR-Passport
## Style guide

### Общее по тексту

|:------------------------:|:----------------------------:|:----------------------:|
| Взаимодействия с кнопкой | Нажмите кнопку **Применить** |    Нажмите на кнопку   |


### Раздел «История изменений». Как оформлять?
- заголовок 2 уровня → Месяц и год изменения
- заголовок 3 уровня → Классификация изменения:

  - Новый функционал
  - Исправление ошибок
  - Улучшение


### Префиксы коммитов


| Префикс |                           Значение                           |                               Пример из репозитория                              |
|:-------:|:------------------------------------------------------------:|:--------------------------------------------------------------------------------:|
|   feat  |      feature — новая возможность, заметная пользователям     |  «feat: кнопка скачивания PDF в шапке», «feat: карточки контактов техподдержки»  |
|   fix   |                      исправление ошибки                      |                       «fix: верный путь к custom.js в .yfm»                      |
|  chore  | хозяйственное — уборка, настройки, переезды; ни фича, ни баг | «chore: игнорировать локальную сборку», «chore: переезд на docs.qrpassport.tech» |
|    ci   |       изменения в автосборке (workflow, GitHub Actions)      |                   «ci: зафиксировать версию yfm 5.15.2 для PDF»                  |


- **docs** — правки текста документации: «docs: обновили раздел Сертификаты»;
- **style** — внешний вид без изменения логики: «style: цвета карточек в тёмной теме»;
- **refactor** — переделка «внутри» без изменения поведения;
- **revert** — откат предыдущего коммита.
